# Security Documentation

This directory documents the security practices implemented in the project.

## Security Components

- IAM roles and policies
- Least-privilege permissions
- Lambda execution roles
- EventBridge execution roles
- S3 access permissions
- DynamoDB access permissions
- SQS and SNS permissions
- Secrets Manager

Sensitive information such as passwords, access keys, account credentials, and secret values must never be committed to this repository.
